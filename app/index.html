SafePay — Freelance Escrow on MST

Client locks payment on-chain. Funds release per milestone only after client approval. Unreleased funds refund after the deadline. Real MST Testnet contract — no simulations.

Demo flow: 1. Connect BridgeKey → 2. Switch to MST Testnet → 3. Create escrow → 4. Fund it → 5. Freelancer delivers with proof → 6. Client approves → 7. Release it. Or, after the deadline: freelancer claims delivered work, client refunds only undelivered funds. Every step is a real on-chain transaction. Gasless mode (section 2) signs the same actions as meta-transactions and lets a relayer submit them and pay the gas — funding stays direct-only by design.

2. Contract

Switching mode resets the contract address below to that mode's default. Direct is the default; the v2 contract is unchanged.

The relayer service runs on demand, not hosted 24/7. Start it first: RELAYER_PRIVATE_KEY=<funded test key> node relayer/relayer-server.js (default port 3001, see docs/relayer.md). Then check its status below.


    
Gasless actions are signed by you (EIP-712) and submitted by the relayer, which pays the gas. The escrow still records you as the actor. Funding is never relayed — it moves your own money, so Fund stays direct-only.
