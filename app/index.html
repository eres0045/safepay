SafePay — Freelance Escrow on MST

Client locks payment on-chain. Funds release per milestone only after client approval. Unreleased funds refund after the deadline. Real MST Testnet contract — no simulations.

Demo flow: 1. Connect BridgeKey → 2. Switch to MST Testnet → 3. Create escrow → 4. Fund it → 5. Freelancer delivers with proof → 6. Client approves → 7. Release it. Or, after the deadline: freelancer claims delivered work, client refunds only undelivered funds. Every step is a real on-chain transaction. Gasless mode (section 2) signs the same actions as meta-transactions and lets a relayer submit them and pay the gas — funding stays direct-only by design. New for Demo Day: role dashboards (section 6) show each side's live escrows, and the dispute contract (section 5) lets either party freeze an escrow and a designated resolver settle it.

2. Contract

Switching mode resets the contract address below to that mode's default. Direct is the default; the v2 contract is unchanged. Dispute mode hides the gasless buttons: dispute actions are direct-only, because the relayer service only relays to the relayer escrow.

The relayer service runs on demand, not hosted 24/7. Start it first: RELAYER_PRIVATE_KEY=<funded test key> node relayer/relayer-server.js (default port 3001, see docs/relayer.md). Then check its status below.


    
Gasless actions are signed by you (EIP-712) and submitted by the relayer, which pays the gas. The escrow still records you as the actor. Funding is never relayed — it moves your own money, so Fund stays direct-only.

  5. Disputes (dispute contract only)
  
Either party to an escrow can raise a dispute with a reason; while disputed, release, deadline-claim, and refund are all frozen. The designated resolver — set at creation, defaulting to the client — settles the whole remaining balance to the freelancer (release) or back to the client (refund). A client-as-resolver is NOT neutral: for a real dispute, create the escrow with an independent resolver address. All dispute actions below are direct-only (you pay gas); the relayer service only relays to the relayer escrow. Use the Dispute mode in section 2 so the contract address points at the dispute contract.
